# 部署上线（目标：手机 4G 能打开的公网链接）

> 只有两个动作需要你亲手点：注册平台、点 Deploy。代码不用改。

## 方案 A：Render（推荐，10 分钟，免费）

1. 打开 https://render.com ，用 GitHub 账号登录。
2. 把 `notice-radar` 这个文件夹推到你的 GitHub 仓库（或直接用 Render 的 "Public Git repository" 填地址）。
   - 命令行三行：
     ```
     cd notice-radar
     git init && git add . && git commit -m "notice-radar"
     ```
     然后在 GitHub 新建仓库，按它给的 `git remote add origin ...` + `git push -u origin main`。
3. Render 控制台 → New → **Blueprint** → 选仓库 → 它会自动读 `render.yaml` → 点 **Apply**。
   - 若 Blueprint 报错，改用 New → **Web Service**：
     - Build Command：`pip install -r requirements.txt gunicorn`
     - Start Command：`gunicorn -b 0.0.0.0:$PORT -w 2 --timeout 60 app:app`
4. 等 2–3 分钟，拿到 `https://xxx.onrender.com`。
5. **验收**：手机关 WiFi、开 4G，打开这个链接，点「竞赛通知」→「开始解析」，截图。

> 免费实例 15 分钟无访问会休眠，首次打开等 30 秒。答辩前先自己点一次唤醒。

## 方案 B：华为云 AI 开发者空间（如果码道沙箱能直接发布）

码道 WebUI 生成应用后会起一个内部预览链接，继续对它说：

> 用 DevBridge 生成公网分享链接，端口 8000。

拿到链接直接当公网地址用（沙箱重置后会失效，仅适合演示）。

## 方案 C：Docker 任意平台（Railway / 阿里云函数计算 / 腾讯云托管）

仓库里已有 `Dockerfile`，任何支持容器的平台都能一键跑：
构建 `docker build -t notice-radar .`，运行 `docker run -p 8000:8000 notice-radar`。

## 止损线

**40 分钟内没拿到可用链接，立刻停手**，改成本地录屏演示。不要在部署上耗掉半天。
录屏时把地址栏显示成 `127.0.0.1:8000` 也没关系——评委会理解本地运行，
但你必须在作品说明里写清"本地一键启动，附 `run.bat`"。
